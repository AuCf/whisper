专为沉浸写作而设计

拒绝繁复堆砌，把纯粹的写作体验还给每一个创作者

交互式思维导图模式

基于 Marked AST 语法树生成交互式标题导图。支持自由平移缩放，点击节点即可平滑滚动跳转至对应文本段落。

工作区全局精准搜索

快捷键 Ctrl+Shift+F 触发，Rust 后端快速扫描工作区文件与内容行上下文，支持快捷键模糊查词定位。

80KB 智能截图粘贴

按 80KB 临界值智能切分：小截图直接转 Base64 嵌入（零多余文件夹），大图自动收纳至存储库，保持目录绝对干净。

双重排版与消光配色

内置 GitHub Standard 与 VitePress Tech 双重渲染效果。提供消光 Dark、GitHub Light 与 Solarized 三大精致主题。

全自动增量平滑升级

完美接入 Tauri 2.0 签名更新机制。启动无感检测，检测到新版本时工具栏自动浮现脉冲小黄点，一键更新重启。

标签页会话持久还原

应用关闭或重新启动时，自动还原上次打开的所有文件标签页状态，配合全局阅读状态栏，随时记录写作节奏。
