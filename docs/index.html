Powerful Features

专为沉浸写作而设计

拒绝繁复堆砌，把纯粹的写作体验还给每一个创作者

Marked AST 驱动

交互式思维导图模式

基于语法树动态提取标题大纲，支持自由缩放平移。点击导图节点，自动退出并平滑滚动高亮定位至对应文本。

Rust 原生加速

全局工作区精准搜索

快捷键 Ctrl+Shift+F 开启，Rust 后端快速扫描工作区文件与匹配行上下文，支持模糊查词与一键行高亮定位。

80KB 阈值切分

80KB 智能截图粘贴

按 80KB 临界值智能切分：小截图直接转 Base64 嵌入（零多余文件夹），大图自动收纳至存储库，保持目录绝对干净。

多风格预设

双重排版与消光配色

内置 GitHub Standard 与 VitePress Tech 双重排版效果。提供消光 Dark、GitHub Light 与 Solarized 三大精致主题。

Tauri 2.0 增量包

全自动增量平滑升级

完美接入 Tauri 2.0 签名更新机制。启动无感检测，检测到新版本时工具栏自动浮现脉冲小黄点，一键更新重启。

会话持久化

标签页会话持久还原

应用关闭或重新启动时，自动还原上次打开的所有文件标签页状态，配合全局阅读状态栏，随时记录写作节奏。
