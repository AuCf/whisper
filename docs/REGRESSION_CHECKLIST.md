# Whisper 发布前回归清单

每次准备升级版本时，先运行自动测试，再使用开发模式完成桌面端人工检查。建议在 Windows 上完成全量检查，发布多平台安装包时再补充对应系统的启动与安装验证。

## 自动测试

```bash
npm test
```

自动测试覆盖 Markdown 标题锚点、代码高亮、KaTeX、Mermaid 源码转义、思维导图大纲生成，以及外部修改冲突时的防覆盖写入。GitHub Alert 与当前 Marked 版本的兼容性已登记为待修测试项。

## 编辑与文件

- [ ] 新建文档后可以输入、保存和另存为 `.md` 文件。
- [ ] `Ctrl+S` 保存当前文档，脏状态标记随之消失。
- [ ] `Ctrl+R` 只重新载入当前标签，不刷新整个应用。
- [ ] 当前文档存在未保存修改时，重新载入会先请求确认。
- [ ] 当前文档没有本地修改时，使用其他程序修改文件后 Whisper 会自动刷新内容。
- [ ] 当前文档同时存在本地和外部修改时，Whisper 会暂停自动保存并提示处理冲突。
- [ ] 冲突提示中选择“保留当前”后，手动保存会再次确认是否覆盖磁盘内容。
- [ ] 同时打开多个标签后，可以切换、关闭和从溢出列表定位标签。
- [ ] 关闭包含未保存修改的标签或应用时，会显示确认提示。
- [ ] 退出并重新启动后，标签页、工作区、主题和视图状态能够恢复。

## 工作区与系统集成

- [ ] 可以保存并切换多个工作区，工作区文件树支持展开和收起。
- [ ] 快速打开 `Ctrl+P` 和全局搜索 `Ctrl+Shift+F` 能定位目标文件。
- [ ] 拖入 Markdown 文件可以打开。
- [ ] 将 Whisper 设置为 `.md` 默认应用后，双击文件能直接打开该文件。
- [ ] 窗口最小化、最大化、关闭正常，`F11` 进入全屏后可按 `Esc` 返回。

## Markdown 预览

- [ ] 标题、表格、任务列表、引用、链接和图片渲染正确。
- [ ] JavaScript、Python 等代码块正确高亮，复制按钮复制的是纯代码。
- [ ] 行内公式和块级 KaTeX 公式正常显示。
- [ ] 合法 Mermaid 图表正常显示；错误语法只在图表位置提示，不在页面底部残留错误图形。
- [ ] 大纲和思维导图可以跳转到对应标题。
- [ ] 本地图片路径能够预览；在编辑器中粘贴剪贴板图片后会自动保存并插入 Markdown 引用。

## 导出

- [ ] HTML 导出后可在浏览器独立打开，样式和正文完整。
- [ ] PNG 导出内容宽度、中文排版、代码块和图片正确，不出现空白或竖排文字。
- [ ] PDF 直接保存为文件，分页、中文、代码块和图片正确，不打开系统打印窗口。
- [ ] 深色、浅色及各排版预设下至少各验证一次导出结果。

## 响应式与外观

- [ ] 小于 `1100px` 时大纲自动收起。
- [ ] 小于 `900px` 时默认使用单栏视图。
- [ ] 原生标题区、工具栏、标签栏和应用图标在深浅主题下显示协调。

## 发布

- [ ] `package.json`、`src-tauri/Cargo.toml` 和 `src-tauri/tauri.conf.json` 版本号一致。
- [ ] Windows 安装包可以安装、启动和卸载。
- [ ] macOS 的 Apple Silicon 与 Intel 产物均生成成功。
- [ ] Linux 仅生成 `.deb` 和 `.AppImage`，安装或运行验证通过。
- [ ] Release 中包含签名产物和 `latest.json`，应用内检查更新可以识别新版本。
